# Fakebook (ফেকবুক)
Fakebook – যেখানে সবই ভুয়া, শুধু সার্কাজমটা আসল। ফেসবুকের বাংলা প্যারোডি, পুরোটাই মজার জন্য।

## ফোল্ডার
```
fakebook-site/
├── index.html        পুরো সাইট (হোম, প্রোফাইল, রোস্ট, গ্রুপ, ইভেন্ট, মার্কেটপ্লেস ইত্যাদি)
├── 404.html          সার্কাজমওয়ালা ৪০৪ পেজ
├── vercel.json       Vercel কনফিগ
├── package.json
├── api/chat.js       রিয়েল-টাইম সার্কাজম চ্যাটের সার্ভার ফাংশন (ঐচ্ছিক)
└── assets/
    ├── icon.png      অ্যাপ আইকন (ফেভিকন, নেভবার)
    └── logo.png      লগইন পেজের লোগো
```

## GitHub + Vercel ডিপ্লয় (৩ ধাপ)
1. জিপ এক্সট্র্যাক্ট করে `fakebook-site`-এর ভেতরের সব ফাইল একটা নতুন GitHub repo-তে আপলোড করো (index.html যেন repo-র রুটে থাকে)।
2. vercel.com → Add New → Project → repo ইমপোর্ট করো। Framework Preset: **Other**, Build Command ফাঁকা।
3. Deploy চাপো। ব্যস, সাইট লাইভ।

## চ্যাটে আসল AI-সার্কাজম চালু করতে (ঐচ্ছিক)
Vercel → Project → Settings → Environment Variables:
- `ANTHROPIC_API_KEY` = তোমার API key (এটা কখনো index.html বা GitHub-এ লিখো না)
- (ঐচ্ছিক) `ANTHROPIC_MODEL` = অন্য মডেল ব্যবহার করতে চাইলে

এরপর Redeploy করো। key না দিলেও সাইট কাজ করে: তখন বিল্ট-ইন সার্কাজম ইঞ্জিন সময়, তারিখ, হিসাব, প্রেম, টাকা, চাকরি ইত্যাদির প্রশ্নের উত্তর দেয়।
সতর্কতা: AI চালু থাকলে ব্যবহারকারীর প্রতিটা মেসেজের জন্য API খরচ হয়। ফাংশনে সামান্য রেট লিমিট দেওয়া আছে, তবু Anthropic ড্যাশবোর্ডে খরচের সীমা বসিয়ে রেখো।
